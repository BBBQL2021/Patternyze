## 详细介绍

Patternyze，天才Agent工程师的前端助手工具。

把网页上的组件和问题，整理成开发人员能看懂的材料。适合前端开发、产品、业务和测试人员使用。

【组件采样】
在网页上悬停高亮、点击选择组件，查看视觉样式、尺寸和结构。支持多个区域选择，复制 Markdown 采样内容；单组件还可转换为 Figma 粘贴数据。来源链接默认附带，也可关闭。

【问题反馈】
选择发生问题的区域，填写问题描述、期望效果和复现步骤，整理元素定位信息并复制给开发。无需填写代码，也无需注册扩展账号。

【截图标注】
截取当前可见页面，放大查看并用文字、序号、箭头、矩形、圆形和线条标注。支持颜色、粗细、字号调整，滚轮缩放和拖动模式；可下载标注图片。

【现场诊断】
主动开启记录、操作复现问题，再停止记录。反馈可附带开启后的控制台错误与网络请求状态、耗时和失败信息；不保存请求头、请求体和响应正文。可下载包含截图与诊断信息的完整反馈文件。

【数据由你决定如何分享】
采样与反馈主要在本地内存处理，不自动发送给开发人员。复制和下载由你主动触发。Figma 转换可能请求页面图片和字体 CDN。分享前请检查截图、日志和网页内容中的敏感信息。

使用提醒：截图与记录使用 debugger 权限，浏览器可能显示调试提示；浏览器内部页、商店页面或企业策略限制的页面可能无法使用。截图只覆盖当前可见区域，日志不能追溯开启前的记录。组件采样不恢复原网站后台业务逻辑。

## 单一用途

帮助用户采集网页界面的视觉与诊断上下文，生成供开发人员使用的组件采样和问题反馈材料。

## 权限理由

- activeTab：用户点击扩展或快捷键后，临时访问当前标签页以选择网页组件、生成定位信息。
- scripting：向当前标签页注入组件选择和反馈界面；用户选择 Figma 转换时加载扩展包内的转换器。
- clipboardWrite：仅在用户点击复制时写入组件采样或问题反馈内容。
- debugger：用户主动截图时获取当前页面可见区域；用户点击开始记录后获取目标标签页的控制台异常及网络请求元数据，用于问题定位。可停止与清空，最长记录 5 分钟，错误和请求各最多 100 条。

## 审核测试步骤

无需扩展账号。打开普通 HTTPS 网页（例如 example.com），点击工具栏 Patternyze 图标，然后点击“选择控件”，选择标题或段落。检查 Markdown 预览，切换来源链接，再复制。

开启“多选”，选择另一块不重叠区域，点击“完成选择”，检查选区编号与预览。

切换“问题反馈”，填写问题描述、期望效果、复现步骤。点击“截图 / 重拍”，点击缩略图进入标注编辑器。尝试矩形、箭头、文字（双击画布）、拖动和滚轮缩放，保存并下载标注截图。

点击“开始记录”后操作页面或在原站点刷新，重新打开扩展面板并选择区域后可查看诊断状态；点击“停止记录”，检查诊断预览和完整反馈下载。没有异常的页面可能没有控制台错误，属于正常行为。使用“清空记录”删除临时数据。

浏览器内部页、Chrome Web Store 页面不能作为采样测试页。若 DevTools 或其他调试器占用当前页，先关闭它们再测试记录。Figma 粘贴功能需用户自己的 Figma 环境。
