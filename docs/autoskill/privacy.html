AutoSkill 隐私政策

更新日期：2026 年 11 月 16 日 · 适用版本：1.0.1、1.0.2

AutoSkill 是一个网页工作流录制器。我们处理以下数据，是为了把您主动录制的网页操作整理为可复用的技能包。

何时录制

您在侧边栏点击开始或继续录制后，扩展仅录制当前标签页上所选网站的操作，以及同源内嵌页面上的操作。首次录制该网站时，Chrome 会询问是否授权。离开该网站、关闭录制标签页、停止或清空后，录制结束。您可以在 Chrome 的扩展程序管理页撤销网站权限。

处理的数据

  • 录制页面的网页地址、链接及录制时间。扩展移除 URL 中的用户名、密码和片段，并替换查询参数值；路径及参数名仍可能含有敏感信息。
  • 点击、填写、选择、滚动、拖拽等操作，以及定位操作目标所需的部分标签、文字、属性或坐标。扩展不读取浏览器历史记录库。
  • 您填写的技能名称、说明、变量和断言等内容。默认不保留表单的原始输入或选项值。主动开启“保留填写示例值”后，普通表单值可能进入草稿和导出文件。扩展会尝试识别密码、验证码、密钥等字段并跳过其值。不能识别页面或元素定位信息中的所有敏感数据，请避免录制敏感页面。

保存、导出和删除

录制数据仅在当前 Chrome 配置的本地存储中处理，不使用 Chrome 同步、账户登录、分析或遥测。草稿保留到您点击“清空”或卸载扩展。扩展不会将录制数据上传给开发者、发送给 AI 服务或自动分享给其他方。

您点击复制或下载时，扩展会把所选内容写入系统剪贴板或本地 ZIP。复制或下载后请自行检查并管理这些副本。您主动把内容交给其他软件、在线服务或个人后，后续处理由接收方的政策和您的分享方式决定。

限制使用与联系

AutoSkill 不出售用户数据，不用于广告、评估信用或放贷，也不用于与网页录制和技能导出无关的目的。AutoSkill 对 Chrome API 所提供信息的使用遵守 Chrome 网上应用店用户数据政策及其限制使用要求。

如对数据处理有疑问，请联系 lx@bbbql.com。如果数据处理方式发生变化，我们会更新本政策及商店声明。
